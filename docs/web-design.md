# UniversalForward 管理界面设计

管理界面采用黑白灰的管理工作台：浅灰导航侧栏、白色内容区、细边框和黑色主按钮。渠道与请求日志是两个独立页面，设置与连接测试在弹窗中完成，原始记录在右侧详情抽屉中查看。导航、列表、表单、状态和弹窗共享同一套字体、间距与控件。

## 设计参考

- [shadcn/ui Dashboard](https://ui.shadcn.com/examples/dashboard)：借鉴导航与内容的分区、黑白灰控件、轻量边框、统计卡片和对齐表格。
- [Ant Design 数据展示](https://ant.design/docs/spec/data-display)：按信息重要程度和操作频率组织内容；结构化信息对齐展示；详细说明渐进展开；为空结果和长文本提供明确处理。

页面样式与图标均嵌入插件，不依赖外部字体、样式库或 CDN。参考用于布局与交互设计。

## 页面约定

| 区域 | 行为 |
| --- | --- |
| 工作台导航 | 侧栏切换渠道管理与请求日志；桌面可收起侧栏；手机端采用遮罩导航，并支持键盘焦点与 Escape 关闭 |
| 渠道概览 | 分别统计全部渠道、启用渠道、所有渠道的启用 Key，以及去重后的模型；每项说明统计含义，不推断流量或成功率 |
| 渠道管理 | 默认以卡片展示，支持切换为对齐渠道身份、模型、访问密钥、路由与操作的列表；记住主动切换的视图；搜索或状态筛选不拉伸单张卡片；禁用渠道使用灰色背景与「已禁用」标识，文字保持清晰，重新启用恢复正常样式 |
| 渠道操作 | 名称和编辑按钮进入设置，模型数量直接进入模型页；连接测试与启用／禁用按钮常驻；禁用渠道显示黑色「启用」按钮；日志和删除放在更多菜单中，支持键盘导航 |
| 渠道设置 | 六个设置页共享侧栏，手机端转换为可滚动标签；基础设置按渠道信息、上游连接与兼容性分组；内容单独滚动，保存栏固定可见 |
| Key 与协议 | Key 按行编辑名称、完整访问密钥、启用状态和顺序；名称默认取末尾 4 位，自定义名称保留；名称与密钥输入框同高，启用与操作在同行居中；已有密钥留空保留；模型协议逐条展开自定义配置 |
| 思考等级 | 不改写、按值映射与固定等级使用带图标与选中标记的选项卡；映射行、默认等级、固定等级和预览统一为可搜索且支持自定义值的组合框，等级为 14px 深色文字；常用值仅作建议；继承规则时禁用控件并保留文字对比度 |
| 连接测试 | 端点、输出上限、流式模式与提示词集中配置；提交成功后收起参数并显示配置摘要；结果显示模型、Key、状态码和耗时；分页栏固定可见 |
| 请求日志 | 独立页面默认展示模型、请求类型与执行状态筛选；时间、渠道、Trace 等条件按需展开；渠道范围可清除；表格独立滚动，分页栏固定可见 |
| 日志信息 | 渠道与模型等主要文字使用 15px，日期、Trace、耗时与思考摘要使用 13–14px；次要文字采用深灰，状态标签使用深色文字；筛选、分页与详情原文同步放大；完整模型、代理身份、参数与重试记录保留在详情；未提供和未返回保持明确区分 |
| 手机端结果 | 日志与测试表格转换为逐条展示；状态、模型和详情操作完整可见；测试保留当前页全选 |
| 请求详情 | 日志和连接测试使用同一种右侧抽屉；手机端铺满窗口；原文和长标识允许换行 |
| 空结果 | 渠道可重置筛选或添加；日志与测试表格提供空结果说明 |

## 样式维护

统一修改 `src/Plugins.UniversalForward/Web/styles.css` 中的变量。先修改共用组件，避免为单个页面重复覆盖按钮、圆角和颜色。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `--primary` | `#18181b` | 主操作、选中控件 |
| `--text` | `#18181b` | 标题、正文 |
| `--muted` | `#52525b` | 次要信息，保持白色与灰色背景上的可读性 |
| `--accent-soft` | `#f4f4f5` | 次级控件与选中背景 |
| `--line` | `#e4e4e7` | 面板与表格分隔 |
| `--border` | `#dcdce0` | 输入框与按钮边框 |
| `--surface` | `#fff` | 内容背景 |
| `--subtle` | `#fafafa` | 侧栏、参数区和表头 |
| `--radius` | `7px` | 共用控件圆角 |
| `--panel-radius` | `12px` | 内容面板圆角 |
| `--sidebar-width` | `232px` | 桌面展开侧栏宽度 |

状态不能只靠颜色区分，必须保留文字。图标使用 `app.js` 中的本地 SVG 工具，装饰图标设置 `aria-hidden`。用户提供的名称、模型、地址、日志内容通过文本节点展示。

等级组合框保留输入焦点，用方向键切换建议、Enter 选择；直接输入也会更新预览，Escape 仅关闭选项浮层。浮层根据内容区空间向上或向下展开，选项独立滚动，保持在可视范围内并避开保存栏；切换页签、规则范围或接口时关闭。原有规则协议、自定义值和模型继承行为保持一致。

Key 管理接口返回完整密钥用于编辑，旧掩码字段保留兼容性，输入框不再使用密码类型或另起一行显示掩码。未修改或清空已有密钥时，保存仍使用空字符串保留原值；获取与刷新模型使用已存储的 Key ID，替换密钥后才使用草稿值。默认名称跟随末尾 4 位更新，手动名称不随密钥变化。

## 验证

浏览器测试使用模拟宿主和演示上游，不发送真实转发请求。安装 Playwright 后执行 `tests/browser/*.cjs` 中的测试脚本；环境已有运行库时，可通过 `PLAYWRIGHT_MODULE` 指定模块路径。

执行 `node scripts/preview-web.cjs` 可生成 `artifacts/ui-refactor-20261023/preview.html`。该预览使用演示数据，支持渠道编辑、日志筛选、详情、导出和连接测试；修改只存在于页面内存，刷新后恢复。

执行 `node scripts/preview-web.cjs --serve` 可在本机打开交互预览，地址由脚本输出。

需要检查页面导航、菜单的键盘操作、列表和卡片切换、筛选与空结果、编辑保存、多 Key、协议和请求头配置、思考映射、日志分页和正文，以及桌面、手机和较矮窗口中的滚动与底部操作栏。`tests/browser/workspace.cjs` 还验证页面切换期间的过期请求、移动导航焦点和刷新失败时的数据保留。

页面资源嵌入验证：

```powershell
dotnet test tests/UniversalForward.Tests/UniversalForward.Tests.csproj --filter FullyQualifiedName~PageAndDiscoveryTests
```
