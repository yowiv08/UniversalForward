# 管理界面

UniversalForward 顶部提供渠道、请求日志、外观、插件设置、刷新与添加入口。界面支持白天、黑夜和跟随宿主明暗。

## 渠道管理

渠道默认以卡片显示，也可切换为列表。搜索按名称、地址或模型筛选，状态筛选区分启用与禁用。

概览条显示渠道、已启用渠道、Key 和模型数量。启用与禁用快捷筛选位于渠道列表上方。

名称和编辑按钮打开渠道设置，模型数量进入模型页。连接测试与启停按钮直接可用，「更多」包含日志、复制和删除。

复制操作打开独立草稿，带入全部可编辑配置和完整 Key。副本默认禁用，名称自动避开重名；保存后创建独立渠道，取消不创建。

## 渠道设置

| 页签 | 内容 |
| --- | --- |
| 基础设置 | 渠道名称、地址、认证、连接方式、代理、允许端点和 Responses 资源状态规则 |
| Key 管理 | 批量添加、全选与多选、批量启停和删除、命名、替换、排序、分配策略和自动禁用 |
| 模型与协议 | 模型列表、候选模型、支持协议、首选协议和强制原生 |
| 思考映射 | 渠道默认与模型规则、按值映射、固定等级和预览 |
| 系统提示词 | 不改写、追加、替换和多行文本 |
| 请求头 | 客户端模板、通用配置、接口覆盖、可视化与 JSON 编辑 |
| 重试与映射 | 请求时限、普通重试、限流与空回重试、返回状态码映射 |

保存栏固定可见，手机端页签可横向滚动。未保存内容属于编辑草稿，保存失败时可继续编辑。

「建议总时限」可展开查看等待预算并填入数值。修改参数更新建议值，手动填写的总时限由保存操作提交。

## 连接测试

选择模型、Key、协议、流式模式、输出上限和测试内容。结果显示模型、Key、状态码、耗时和错误信息，支持分页、取消和详情查看。

响应原文在详情面板中按需加载，模型汇总可显示部分成功。桌面可同时查看列表和详情，窄屏在当前测试窗口内切换，关闭详情后返回列表。

测试不自动禁用 Key。完成后点击「禁用 Key」，查看每个 Key 的结果并勾选，确认后禁用。Key 变更后需重新测试。

## 请求日志

日志支持模型、请求类型、状态、时间、渠道和 Trace 筛选。详情展示发送与响应模型、思考参数、Token 用量、代理和各次尝试。

日志详情在右侧弹窗中展示，支持关闭按钮、Escape 和点击遮罩关闭。关闭后焦点回到原记录，列表保留筛选、页码和滚动位置；窄屏弹窗占满视口。

日志说明明确记录范围与内存保存方式。请求与响应正文不采集，连接测试原文通过测试详情查看。

## 外观与操作

「跟随宿主」使用宿主的明暗选择，插件使用自身配色。白天与黑夜可手动固定；外观设置由同一实例的管理员共用。

状态同时使用文字和颜色表示。菜单、页签和等级输入支持键盘操作，Escape 可关闭浮层。长名称、模型和原文可换行，分页与底部操作保持可访问。

## 页面维护

页面文件位于 `src/Plugins.UniversalForward/Web`，公共样式变量集中在 `styles.css`，图标使用本地 SVG。用户输入的名称、模型和日志通过文本节点展示。

`app.js` 负责渠道与编辑状态；公共交互、请求头与状态码映射、连接测试、请求日志、思考映射和插件设置分别组织为模块。页面由插件程序集内嵌资源组装。

浏览器检查脚本位于 `tests/browser`，可通过 `PLAYWRIGHT_MODULE` 指定 Playwright。`node scripts/preview-web.cjs --serve` 提供演示数据预览，预览修改仅存在于页面内存。
