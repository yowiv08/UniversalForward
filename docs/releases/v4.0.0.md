# UniversalForward v4.0.0

以 **4.0 正式版**发布当前 UniversalForward 插件，整合请求 CPU 热点修复、正文日志移除和缓存 Token 明细。功能沿用已验证的 v0.3.10，适配 Router2API 2.1.2 / Router.Contracts 2.0.0，运行时为 .NET 10，无需数据库迁移。

- SSE 增量解析只扫描新数据，Claude 长文本汇总使用字符串缓冲，请求准备复用已验证的渠道设置和最终发送内容，减少重复解析、复制及垃圾回收开销。
- 插件收到的请求正文、实际发送正文、上游响应正文和 WebSocket 原文均不采集、不显示、不导出；保留请求元信息、模型、思考参数、请求／响应头、宿主扩展参数、错误及四项 Token 明细。
- 缓存写入兼容 OpenAI 输入明细中的 cache_write_tokens、cached_creation_tokens、cache_creation_input_tokens 及 Claude 顶层总量；总量缺失时可使用明确报告的 TTL 分项。同义总量不重复相加，各次尝试独立记录，摘要采用最后一次尝试。
- 合法零值显示 0，未报告、无效及溢出保持「未返回」，不从输入差值或价格反推缓存写入。超限 SSE 事件后的完整事件继续提取元数据，网络响应继续按既有规则转发。
- 请求日志及日志设置继续保存在本次运行内存，操作队列默认最多 256 项，满时丢弃日志操作并标记不完整。更新或重新加载插件会清空先前的内存日志。

功能验证沿用 v0.3.10 的 889 项插件测试、29 项宿主兼容性测试及日志页面浏览器验证；4.0 发布另行构建、验证发行隔离加载、ZIP 与内容索引，并由 GitHub Actions 完成自动测试及发布。

性能证据见 [请求 CPU 热点与验证](https://github.com/yowiv08/UniversalForward/blob/v4.0.0/docs/cpu-performance.md)，缓存字段与解析上限见 [缓存用量核查](https://github.com/yowiv08/UniversalForward/blob/v4.0.0/docs/cache-usage.md)。
