# UniversalForward v0.3.8

渠道编辑新增「系统提示词」页签，可选择不改写、追加或替换，并填写完整多行文本。默认不改写；关闭时保留文本，保存失败保留草稿，复制渠道带入独立配置。

- 追加保留原提示词：Responses 追加 instructions，Claude 字符串追加或在系统块数组末尾新增文本块，原缓存属性保留。
- 替换使用自定义提示词：Responses 同时移除当前 input 中普通 system／developer 指令消息，显式工具项和动态工具声明保留；Claude 替换 system。Claude Code 模板要求的客户端身份段继续保留。
- HTTP、SSE、Responses WebSocket 与连接测试共用发送前处理；内部重试和宿主再次尝试不会重复累积追加。
- 文本框使用 15px，保留空格与换行，上限 32000；处理说明默认收起，支持键盘、明暗配色和手机布局。
- accounts/save 增加可选 systemPromptPolicy，沿用现有渠道设置存储和 ID 生成流程，无需新增接口或数据库迁移。日志元数据记录处理方式与字段，完整前后请求继续通过原始内容核对。

适配 Router2API 2.1.2 / Router.Contracts 2.0.0，运行时为 .NET 10。设计与开源核查见[系统提示词说明](https://github.com/yowiv08/UniversalForward/blob/v0.3.8/docs/system-prompt.md)。

本地验证通过 765 项插件测试、20 项宿主集成测试及发行隔离与安装包校验；8 组相关浏览器检查覆盖草稿、复制、明暗可读性及 320px／390px 布局。宿主 3 次 × 渠道内部 3 次发送已确认每次只追加一份渠道提示词。
