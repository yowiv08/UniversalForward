# UniversalForward v0.3.5

适配 Router2API 2.1.2，保留渠道、多 Key、协议、代理、重试、超时、状态码映射及现有界面功能。运行时为 .NET 10，继续使用公开 Router.Contracts 2.0.0。

## 宿主尝试与用量

- 渠道页新增「插件设置」，宿主默认尝试次数为 1–35（含首次），默认 1；宿主映射填写具体次数时覆盖，留空继承。原子保存后更新本插件及平台策略，新请求生效，执行中请求保留原快照。
- 保留渠道内部重试，同一内部尝试固定渠道、Key 和代理。可重放失败在内部额度耗尽后返回 `NextAttempt`，交由宿主决定继续或切换目标。参数错误、已识别永久错误、取消、总时限耗尽、已有输出或已交付流时停止重放，不增加账号或代理处罚。
- 页面说明两层次数和三类超时。宿主 3 次、渠道重试 2 次最多普通发送 9 次；异常重试额度和时限仍独立约束。日志增加内部发送数、宿主继续决定、停止原因及 Trace 关联。连接测试继续测试选定渠道。
- 重试页增加实时「建议总时限」和一键填入，默认收起为一行入口，点击后展示建议、差异提示及操作，计算依据与宿主说明进一步展开查看。估算响应头等待、共享异常重试间隔与适用的 520 退避，取宿主建立响应限制后加上响应读取预留，向上取整且最多 3600 秒。展开／收起保留草稿，每次打开渠道设置时默认收起，保留手动填写；宿主限制读取失败可就地重试。建议只针对当前插件调用，不乘宿主尝试次数，不把流空闲当作输出时长，不保证模型完成或用完全部重试。
- 修复 Claude 输入用量未计入缓存读取和写入。普通 JSON、SSE／WebSocket 汇总 JSON 共用规则，保留零值及上游总量，避免重复计入 OpenAI 明细。用量缺失或无效时由宿主解析或估算，不影响正文转发。
- 保留状态码映射；失败映射为 2xx 可能被宿主按成功处理，编辑器提供提示。

## 明暗模式

- 页头新增「跟随宿主／白天／黑夜」，默认跟随 Router2API 2.1.2 的明暗通知，始终使用插件自己的配色。宿主新增或删除配色主题不影响明暗跟随。
- 白天保持原有样式，黑夜使用深灰背景、分层面板和浅色正文。表单、菜单、弹窗、思考等级、测试结果和日志共享配色。日志主要文字保持 15px，正文与说明文字保持至少 4.5:1 对比度。
- 保留默认卡片视图、启用／禁用按钮和禁用渠道独立灰底；切换不重载页面，保留筛选及未保存的内容。处理宿主通用染色与插件自有配色的冲突。
- 外观选择由同一宿主的管理员共用，刷新、重启和升级后保留。读取失败回退白天并提示；切换即时应用、串行保存，失败恢复上次已保存选择。

## 设置与交付

管理员接口 `GET/POST execution/settings` 使用 `defaultHostAttempts`；`GET/POST appearance/settings` 使用 `mode: host | light | dark`。设置分别保存到运行目录的 `data/universalforward/execution-settings.json` 和 `appearance-settings.json`，不放在插件更新时替换的程序集目录。插件原文日志继续保存在本次运行内存中。

本版本针对官方宿主 2.1.2 验证；2.1.2 的隐藏原始模型及持久化总览由宿主直接提供。原渠道配置无需数据库迁移。

下载 `universalforward.zip`，解压后更新插件目录。安装包只包含 UniversalForward，不包含 Router.Contracts.dll；`release-index.json` 提供版本、文件大小和 SHA-256 校验信息。保留宿主运行目录中的 `data/universalforward/`，其中的尝试次数和外观设置会在升级后继续使用。

- 独立构建使用 NuGet Contracts 2.0.0，最终构建的页面嵌入及包隔离检查 5 项通过且无跳过，发布包校验通过。浏览器验证包含官方宿主原版注入脚本，未调用真实模型服务。
