# UniversalForward v4.3.0

UniversalForward 是 Router2API 上游转发插件，支持 Responses、Chat Completions 和 Anthropic Messages，提供渠道管理、多 Key 分配、认证设置、连接测试和请求日志。

运行时为 .NET 10，使用 Router.Contracts 2.0.0。安装文件为 `universalforward.zip`，校验信息见同一 Release 的 `release-index.json`。

## 功能

- 三种原生协议的 JSON 与 SSE 转发，Responses 可选择 WebSocket 上游连接。
- 渠道认证支持 `Authorization: Bearer` 和 `x-api-key`，新建渠道默认 Bearer。
- 多 Key 轮询、随机和主备分配，可按 HTTP 状态码及连续失败阈值自动禁用和切换 Key。
- 渠道与模型的思考等级映射、系统提示词追加或替换、通用及按接口配置的请求头。
- 直连、代理池、指定订阅和固定节点。
- 模型与 Key 的批量连接测试、分页结果、响应详情和取消。
- 请求模型、响应模型、思考参数、Token 与缓存用量、重试和错误日志。

## 使用规则

正常请求保留思考历史和加密状态。「异常时剥离 Responses 资源状态」仅在明确的资源状态错误且尚无有效输出时，剥离相关状态并额外重试一次。

Key 自动禁用默认关闭，默认状态码为 `401,403`，连续失败阈值为 3。禁用状态持久化保存，恢复使用需手动启用。连接测试通过独立选项控制自动禁用。

请求日志与测试结果保存在运行内存，请求及响应正文不进入请求日志。渠道、Key、模型、外观和执行设置按各自配置存储保存。
