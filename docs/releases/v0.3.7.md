# UniversalForward v0.3.7

新增渠道「复制」入口：在卡片和列表的更多菜单中，位于「日志」下方、「删除」上方。

- 点击后打开独立副本草稿，带入完整 Key、名称、顺序、各 Key 启用状态和全部可编辑渠道配置。
- 副本默认禁用，名称追加「 - 副本」，重名自动编号并遵守长度限制；可继续编辑，保存后才创建新渠道和新 Key ID。
- 取消不创建副本，保存失败保留草稿。副本获取模型使用草稿的地址与完整 Key，不引用原渠道 ID。
- 日志、测试记录、运行状态和候选模型缓存不复制。

本次仅新增复制入口及草稿流程。Key 与模型的关联、转发和宿主模型映射保持原有行为，复用现有 `accounts/save`，无需数据库迁移。

适配 Router2API 2.1.2 / Router.Contracts 2.0.0，运行时为 .NET 10。

本次验证通过渠道复制、工作台和多 Key 三组浏览器检查，覆盖完整配置、草稿隔离、保存失败、键盘操作、明暗对比度及 320px／390px 布局；渠道保存、Key 管理和页面资源等 45 项相关 .NET 测试通过。
