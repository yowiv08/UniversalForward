# UniversalForward v0.3.3

重构插件管理界面，统一渠道、设置、日志与连接测试的布局和控件，改善文字可读性及密钥编辑体验。

- 渠道默认使用卡片，支持切换并记住视图；禁用渠道显示灰色背景和明确状态，启用／禁用按钮直接可用。
- 设置使用统一页签和固定保存栏；请求日志独立展示，原始记录使用详情抽屉，支持桌面及手机布局。
- 日志主要文字放大至 15px，辅助信息和详情同步放大，采用深色文字提高对比度。
- 思考映射使用三组处理方式选项卡；等级支持搜索、常用值选择、自定义输入和键盘操作，保留模型继承及接口隔离。
- 密钥名称默认取末尾 4 位，保留自定义名称；访问密钥完整显示，名称、密钥、启用及操作对齐，保留排序、批量添加与重复校验。

兼容 Router2API 2.1.0 / Router.Contracts 2.0.0，运行时为 .NET 10。安装包仅包含 UniversalForward 插件，原渠道配置无需数据库迁移。

下载 `universalforward.zip`，解压后更新插件目录。`release-index.json` 提供版本与文件校验信息。
